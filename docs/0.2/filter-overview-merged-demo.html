Current design (two entries, two interactions)

OverviewMore filters

· Overview: Year/source/relevance; click bars or chips to filter;
· More filters: Citations/score/JCR/impact factor/tier/abstract; select chips to filter.

Two popovers and two mental models: years/sources are selected only in Overview, everything else only in Filters. The same filtering task is split, particularly confusing for newcomers (UX walkthrough #6).
