合并方案：整体概览 + 更多筛选 → 一个「筛选」面板

两者都是「收窄检索结果」的同一件事。合并成单一入口、单一面板，分「分布概览（点选筛选）」与「更多条件」两段。新用户只需理解一个地方。

现状（两个入口、两套交互）

整体概览更多筛选

· 整体概览：年份/来源/相关度，点柱状条或 chip 来筛选；
· 更多筛选：引用量/评分/JCR/影响因子/等级/摘要，选 chip 来筛选。

两个 popover、两种心智，且年份/来源只能在「概览」里点、其它只能在「筛选」里选——同是筛选却分家。对新用户尤其难建立模型（呼应 UX 走查 #6）。
