状态词统一：**已实现**表示代码存在；**已验证**必须说明证据和范围；**计划**表示尚未实现的需求；**待验证**表示技术、渠道或商业假设尚无证据；**待决定**表示需要产品负责人取舍。编译通过、演示回复、供应商展示均不等于真实任务验收通过。
