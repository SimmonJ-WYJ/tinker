# 划词功能演示脚本

## 🎬 演示场景 1: Add to Chat (添加到对话)

### 用户操作流程：

```
1. 用户在 AI 回复中看到一段有用的内容
   ┌────────────────────────────────────────┐
   │ AI: 量子计算是一种基于量子力学原理的  │
   │ 计算方式，它利用量子比特的叠加态和    │
   │ 纠缠态来进行信息处理...              │
   └────────────────────────────────────────┘

2. 用户用鼠标拖动选中其中一段文字
   ┌────────────────────────────────────────┐
   │ AI: 量子计算是一种基于量子力学原理的  │
   │ 计算方式，它利用[量子比特的叠加态和]  │  ← 蓝色高亮选中
   │ [纠缠态来进行信息处理]...            │
   └────────────────────────────────────────┘

3. 松开鼠标后，浮动工具栏淡入显示
   ┌─────────────────────────────────────┐
   │  💬 1 selection                     │
   │  ├─ Ask in sidebar  ├─ Add to chat │  ← 工具栏从上方滑入
   └─────────────────────────────────────┘
           ↓ 工具栏悬浮在选中文本上方
   ┌────────────────────────────────────────┐
   │ AI: 量子计算是一种基于量子力学原理的  │
   │ 计算方式，它利用[量子比特的叠加态和]  │
   │ [纠缠态来进行信息处理]...            │
   └────────────────────────────────────────┘

4. 用户点击 "Add to chat" 按钮
   [点击] → 工具栏淡出消失
          → 引用内容出现在输入框

5. 输入框显示引用内容（Markdown 引用格式）
   ┌────────────────────────────────────────┐
   │ 输入框:                                │
   │ > 量子比特的叠加态和                    │
   │ > 纠缠态来进行信息处理                  │
   │                                        │
   │ █ ← 光标在引用后，可继续输入            │
   └────────────────────────────────────────┘

6. 用户继续输入问题
   ┌────────────────────────────────────────┐
   │ 输入框:                                │
   │ > 量子比特的叠加态和                    │
   │ > 纠缠态来进行信息处理                  │
   │                                        │
   │ 请详细解释这两个概念的区别█             │
   └────────────────────────────────────────┘

7. 发送后，AI 收到带引用的消息
   ┌────────────────────────────────────────┐
   │ User:                                  │
   │ ┌──────────────────────────────────┐  │
   │ │ > 量子比特的叠加态和              │  │
   │ │ > 纠缠态来进行信息处理            │  │
   │ │                                  │  │
   │ │ 请详细解释这两个概念的区别        │  │
   │ └──────────────────────────────────┘  │
   └────────────────────────────────────────┘
```

## 🎬 演示场景 3: 多次选择和取消

### 交互流程：

```
1. 第一次选择
   选中文本 A → 工具栏出现在 A 上方

2. 不点击按钮，直接选中另一段文本 B
   → 工具栏立即消失
   → 新工具栏出现在 B 上方

3. 点击空白区域
   → 工具栏淡出消失
   → 文本选择被清除

4. 点击工具栏按钮
   → 执行对应操作
   → 工具栏消失
```

### 工具栏出现动画：


## 🔍 细节打磨

### 工具栏位置计算：

```
基准点: 选中区域的中心顶部
偏移:   向上 8px，水平居中

计算公式:
  left = selection.left + (selection.width / 2)
  top  = selection.top - toolbar.height - 8px

边界检测:
  if (left < viewport.left + toolbar.width/2)
    left = viewport.left + toolbar.width/2
  
  if (left > viewport.right - toolbar.width/2)
    left = viewport.right - toolbar.width/2
  
  if (top < viewport.top + 8)
    top = selection.bottom + 8  // 切换到下方显示
```

### 响应式适配：

```
桌面 (>= 1024px):
  └─ 完整工具栏，所有按钮横向排列

平板 (768px - 1023px):
  └─ 紧凑模式，减小间距和内边距

移动 (< 768px):
  ├─ 只显示图标，隐藏文字标签
  └─ 或竖向排列按钮
```

## 🎯 交互反馈

### 成功状态：

```
点击 "Add to chat" 后:
  └─ 工具栏消失 + 输入框闪烁聚焦 (300ms)

点击 "Ask in sidebar" 后:
  └─ 工具栏消失 + 侧边栏滑入 (300ms ease-out)
```

```
如果操作失败 (例如输入框未找到):
  ├─ 工具栏轻微抖动 (shake animation)
  └─ 显示 toast 提示: "操作失败，请重试"
```

### 加载状态：

```
如果操作需要时间:
  ├─ 按钮显示 loading 图标
  ├─ 禁用其他操作
  └─ 完成后恢复
```
