# 会话图片与对比界面修正

状态：用户已授权实现并提交到 GitHub。初始基线 main c646b75，提交时已整合最新 main 4b0ad6a。来源：Tinker-A 当前项目反馈。

## 范围与设计

1. 横线导航：已在运行中的0.1.606白底会话右侧核对到灰黑短横线，源码为ScrollMinimap。仅撤掉AgentMessages的组件挂载与值导入，源组件和标签页预览缓存保留；正常滚动、回到底部、任务加载/状态继续保留。不删除消息或数据。
2. 版本对比：删除两图后的灰色容器，保持左右两列、标题和图顶边对齐、自然比例与完整可见。长说明不再占视觉空间，保留屏幕阅读器描述，维持明确父版本、缺图提示、关闭与焦点返回。
3. 已发送图片引用：发送时把精确原图版本的结构化元数据保存到用户消息；后端以已验证版本账本为准，实时/历史渲染真实缩略图，点击可查看，缺失可降级。旧消息字段缺省继续兼容，不迁移真实历史，不按latest猜图。对有新引用字段的重试沿用已发送消息绑定，保留现有付费/重试保护，不发起新请求。

## 非目标

不处理仅记录的计费确认策略或Generated by署名精简。不改Rust架构，不替换安装版，不调用模型或读写真实会话/密钥。GitHub 提交仅包含本轮相关源码、测试与必要文档，通过独立分支和 PR 交付。运行版0.1.606不会因源码修改自动更新。

## 验证计划

合成数据专项：父版本与关闭、缺图及双语；JSONL保存后重载历史缩略图、相邻版本不串图、读取竞态及失败恢复；保持现有账本/消息字节不变。浏览器使用实际源码与模拟API，在桌面/窄视窗看对比与消息列表。完成后跑相关回归、全仓类型/测试与Electron构建，保留源码diff和本项目验证记录。
