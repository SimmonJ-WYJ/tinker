# 独立生图能力

用户已批准在 ASCI 加入生图配置、测试、Agent 调用、图片预览与保存。

- 新 provider `custom-image`，现有渠道 CRUD/加密配置复用，密钥不进入模型上下文。
- 图片渠道不出现在聊天模型选择器，也不参与聊天模型回退。
- 端点 `/v1/images/generations`；模型 ID 原样使用。默认一张，无自动重试，不自动调用付费测试。
- 手动测试标明会生成一张图片，失败显示脱敏的上游错误信息。
- Agent 宿主工具独立注册，使用已启用图片渠道/模型；缺省首个选择，可在用户请求中指定模型。并发调用拒绝重复。
- 当前支持文字生图与 base64 PNG/JPEG/WebP 响应；不主动下载任意 URL，链接型响应会明确报错。图生图/遮罩编辑/流式预览不在本次范围。
- 图片保存在会话附件目录；工具只回传附件信息，不把大段 base64 写入会话上下文。会话外层直接展示结果，不埋进折叠过程。支持放大和另存为。
- 验证：图片端点/模型发现/恶意响应边界测试，付费探针不自动执行的组件测试，预览保存组件测试，聊天回退隔离测试，类型检查、完整测试和打包构建。真实上游生图需实际密钥和付费调用单独验收。
