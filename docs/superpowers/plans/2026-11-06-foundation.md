# Tinker 第一阶段

已授权：在空仓库独立重建 Rust + Tauri + React/TypeScript，不读取或复制 ASCI 代码。

选择：Rust 负责会话和渠道隔离，React 负责桌面界面，Tauri 只暴露窄命令接口。相比纯网页原型，这保留桌面安全边界；相比直接连接真实模型，演示适配器可先验证交互而无需密钥或费用。

- [x] 检查目录、Git、工具链；独立分支。
- [x] 先写 Rust 测试：切换保留草稿、失败保留消息、空发送拒绝、演示回复明确标识。
- [x] Rust 核心与 React 界面、Tauri 窄接口。
- [x] 密钥仅经原生钥匙串存储；浏览器预览禁用密钥输入。
- [x] 核心测试、前端构建、桌面编译；UI 验收连接超时，钥匙串未实际写入。

本阶段不实现真实模型、流式回复、附件、账户或付费验证。草稿只保留在会话内，不承诺重启恢复。渠道配置不包含密钥的端点、模型可保存在本机。没有提供品牌资产，先使用文字 Tinker 和中性暖色界面，不声称复原最终 Logo。
