# Gewu AI Internal-Test User Feedback

**Date:** 2026-04-26
**Source:** Written records from the ASCI in-person internal-test event
**Organization:** What the user was doing → problem encountered → better behavior / expectation

---

<a id="1-安装阶段"></a>

## 1. Installation

Installing the product → Mac installation was slow. Windows required separate Python / Node.js / Git installation, and antivirus such as 360 blocked or mistakenly deleted files. Some users could not run it without Node.js → Bundle required dependencies for an out-of-box experience, or at least explain why they are needed and what to do if installation fails.

<a id="2-进入工具时强制依赖文献库"></a>

## 2. Mandatory Library Dependency on Entry

A user wanted a review directly → The system required a literature library first, but most researchers present did not use one → Make the library optional and allow reviews directly from search results.

<a id="3-论文检索召回率不足"></a>

## 3. Insufficient Search Recall

Searching a user's research field → Returned 176 papers when the user expected at least 400+. Another expected 3 and received 1 → Improve recall and coverage.

<a id="4-搜不到非-oa-的论文含用户自己的论文"></a>

## 4. Missing Non-OA Papers, Including Users' Own

A user searched for their own 2026 paper → No result because it was non-OA and databases such as Wiley were not covered → Cover more paid/closed sources such as Google Scholar, Wiley, and Web of Science, or retrieve non-OA content after user-authorized IP/account access.

<a id="5-ai-幻觉作者-&#45;论文张冠李戴"></a>

## 5. AI Hallucination: Mixed-Up Authors and Papers

Opening a result → The title was right but the author was a senior labmate, combining same-title papers by different people → Strictly match title, author, and DOI. Return no result rather than a mismatched one when uncertain.

<a id="6-字段缺失时被默认填成-1970-年"></a>

## 6. Missing Fields Default to 1970

A 2022 paper appeared with year “1970” → Mark missing fields honestly as “Not found” / “To be completed” rather than defaulting to 1970 and immediately undermining trust.

<a id="7-检索源不透明"></a>

## 7. Opaque Search Sources

A user wanted a result's source → The UI did not identify its database, and reports listed only broad source categories → Each paper card should identify its actual source, such as OpenAlex / PubMed / Google Scholar / Wiley.

<a id="8-搜不到时不应凑数"></a>

## 8. Do Not Fill Gaps When Search Finds Nothing

A user's own article was absent → The system filled results with similar or same-title papers by others rather than reporting no match → Explicitly report no accessible content for the author/scope rather than fill gaps with mismatches.

<a id="9-ai-生成图表后找不到文件"></a>

## 9. Generated Charts Cannot Be Found

The AI claimed a chart was generated and saved → No path was visible, and the file was in a temporary context directory lost on close → Provide a clickable local path in the conversation and save files in a persistent user-workspace directory.

<a id="10-跨页面切换卡顿"></a>

## 10. Slow Page Switching

Switching from the library to the workspace conversation → Noticeable loading delay felt slow → Keep workspace state resident or preload it for seamless switching.

<a id="11-输入框被吃掉"></a>

## 11. Input Gets Stuck

A Windows user entered a message → It would not send without restarting, reproduced on at least two Windows machines → Fix input stability and preserve drafts when errors occur.

<a id="12-mac-&#45;windows-ui-不一致"></a>

## 12. Mac / Windows UI Inconsistency

Comparing the same screen → Windows rendering looked abnormal relative to Mac → Verify cross-platform UI parity.

<a id="13-默认权限弹窗太多"></a>

## 13. Too Many Default Permission Dialogs

Users were interrupted for permission at every step → Frequent interruptions → Default to fully automatic mode and ask only for high-risk actions such as file writes or downloads, leaving ordinary actions unblocked.

<a id="14-任务跑得久-&#45;进度反馈不直观"></a>

## 14. Long Tasks and Unclear Progress

A full search + review took 30~60 minutes → No clear progress bar or ETA, only scrolling logs → Show top-level current stage X/Y and estimated remaining time, beyond the log stream.

<a id="15-最新等模糊词无澄清"></a>

## 15. No Clarification of Vague Terms Such as Latest

A user requested latest progress → Search ran immediately without aligned dates → Clarify years/discipline for latest, recent, or relevant, or choose an explicit default range and disclose it in results.

<a id="16-中英文检索源未自动分流"></a>

## 16. No Automatic Chinese/English Source Routing

A research topic had English papers mainly in international journals → Users expected English topics routed to English sources and Chinese topics to Chinese sources → Select source combinations using topic language/domain.

<a id="17-用户对产品定位的反馈来自微软研究院老师"></a>

## 17. Product Positioning Feedback from a Microsoft Research Researcher

The user wanted abstract questions translated into mathematical models, such as water-molecule motion → Search/review could not help with abstract physical modeling → State capability limits clearly: reviews/data analysis are supported, abstract modeling still needs people. Offer advanced paths such as a coding agent or modeling-Skill marketplace.

<a id="第二轮反馈补充来自-1v1-试用录音-&#45;化学博士-&#45;技术支持2026-04-26-下午"></a>

# Second Feedback Round (1:1 Trial Recording — Chemistry PhD + Technical Support, Afternoon of 2026-04-26)

<a id="18-windows-装不上卸不掉"></a>

## 18. Windows Cannot Install or Uninstall

An older Windows 10 machine → After three installation attempts, the app still would not launch: default C drive, D drive, and after disabling 360 real-time monitoring/firewall. Uninstalling also failed → Improve compatibility testing, especially with 360, long-unused machines doing background updates, non-English paths, and non-Administrator users. Provide a clear recovery path when uninstall fails.

<a id="19-检索相关度只匹配到研究方法匹配不到研究对象"></a>

## 19. Relevance Matches Methods but Not Research Objects

Research on acrylonitrile-butadiene rubber polymers + carbon-spectroscopy characterization → Results shared the method but studied glucose or other polymers and were useless to the user → Distinguish method similarity from object similarity, prioritizing the research object in strongly domain-specific topics such as chemistry.

<a id="20-检索结果列表缺少相关度评分"></a>

## 20. No Relevance Scores in Search Results

Users opened every item to judge relevance → Cards had no score, forcing title-based judgment → Add a score such as 0–100 or ★★★★★, with sorting and low-score filtering.

<a id="21-时间字段混淆capture-time-当成-publication-time"></a>

## 21. Capture Time Confused with Publication Time

A user asked whether a card showed capture time rather than publication time → Clearly distinguish publication year from capture/indexing time with labels.

<a id="22-部分结果缺摘要-&#45;缺关键词且未标注"></a>

## 22. Missing Abstracts / Keywords Are Not Marked

Some papers had only titles, with no abstracts/keywords or explanation → Mark unavailable abstracts / fields not supplied by the source instead of leaving blanks.

<a id="23-会话回退到某节点后再提问会报错"></a>

## 23. Asking After Rewinding Breaks the Session

A user found the direction wrong, rewound to an earlier node, and continued → “no message / session ID not found” invalidated the whole session → Allow continuation after rewind, retain the session ID, and rewrite context-trimming logic.

<a id="24-ai-输出的综述格式不像学术综述"></a>

## 24. Generated Reviews Do Not Look Like Academic Reviews

The user's first response was that the output was completely unlike the expected review → It resembled assembled points without the usual background → current state → method comparison → controversies → outlook structure → Offer discipline-appropriate academic-review templates rather than only topical summaries of multiple papers.

<a id="25-综述只基于摘要-&#45;meta未基于-pdf-全文做语义理解"></a>

## 25. Reviews Use Abstracts / Metadata Instead of Semantic PDF Understanding

The user explicitly wanted full-text PDF understanding rather than keyword understanding → Extract semantic evidence from downloaded full texts instead of assembling metadata and abstracts alone.

<a id="26-引用必须可定位可跳转可悬停预览"></a>

## 26. Citations Must Be Locatable, Clickable, and Previewable

The strongest recurring request was to identify the paper and paragraph behind every conclusion. The user valued search results + accurate source correspondence more than the review itself → Add clickable superscript references, navigation to the paper, and hover previews of source paragraphs.

<a id="27-ai-思考过程暴露不够深"></a>

## 27. Insufficient Visibility into Reasoning

The collapsed process still did not show which papers supported each conclusion → Show the causal link from conclusions to papers and evidence passages as well as searched keywords.

<a id="28-第二轮检索被当成新课题重新从头跑"></a>

## 28. Second Search Treated as a New Topic

A user narrowed a direction from first-round results → The AI restarted a full web search, wasting time and context → Distinguish new topics from refinement/supplementary search and incrementally expand existing results for the latter.

<a id="29-屏幕息屏后任务停止运行"></a>

## 29. Tasks Stop When the Display Sleeps

A technician observed that the Mac Agent stopped when the screen went dark and needed constant mouse movement → Long tasks should continue in the background independently of foreground UI. Also support push/email result notifications when the computer is unavailable/asleep.

<a id="30-用户期望直接对接-zotero而不是另做一套文献管理"></a>

## 30. Integrate Zotero Rather Than Rebuild Literature Management

The user depended on Zotero's mature plugins for translation, PDF downloads, Chinese parsing, AI summaries, reading-time tracking, and tag styles → They wanted Zotero integration rather than duplicate OpenSci features → Provide bidirectional plugin-level synchronization and focus on AI search/review.

<a id="31-期望按-doi-自动获取-pdf结合学校-ip"></a>

## 31. Automatic DOI-to-PDF Retrieval with Institutional IP

The user said Zotero could retrieve 80% of PDFs from DOIs on the campus network → Support DOI → automatic PDF download and user-authorized campus IP / institutional accounts for paid papers rather than manual per-paper downloads.

<a id="32-安装环境强制走默认-c-盘-&#45;默认路径"></a>

## 32. Forced Default C-Drive / Path Installation

D-drive installation failed, and support said only default C-drive installation had been developed/tested → Support and test custom paths, or explicitly disclose a C-drive-only restriction at the first installer step to prevent repeated attempts.

<a id="33-现场用户反馈界面简洁度-ok正向"></a>

## 33. Positive Feedback: UI Simplicity Is Acceptable

Users found the three-column layout (left directory, center conversation, right papers) simple and direct, without excessive complexity or small text → Retain the information hierarchy while adding relevance scores, citation superscripts, and missing-field indicators.
